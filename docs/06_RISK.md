风险等级 = 可能性(P:1–3) × 影响(I:1–3)，≥6 高、3–4 中、≤2 低。每条给触发信号（如何发现）+ 缓解措施（事前预防 / 事后处置）+ 责任方。

## 1. 风险条目

### R1 数据偏差 —— 合成/标注数据分布不等于真实审美分布

| 项 | 内容 |
|---|---|
| 等级 | P=3, I=3 → 9 **高** |
| 描述 | 合成数据生成器受种子模板与算法美学限制（构图规则化、色彩空间窄），标注员人口学单一（年龄/文化/专业偏斜）；训练集若以合成+少数标注员为主，模型学到"生成器偏好"而非人类偏好，泛化到真实照片时四子分整体漂移。 |
| 触发信号 | 合成集与标注导出集上四子分分布 KS 检验 p<0.01；单标注员贡献 >30%；真实 holdout 上 MAE 比验证集高 >30%。 |
| 缓解·事前 | ① 合成生成器种子参数宽域采样（三分法/黄金比/对角/中心/非常规五类构图均 ≥15%）；② 标注平台至少 3 名独立标注员/样本，`rater_count≥3` 入库门禁（C-DATA-01 §3.2 R1）；③ 数据分层报告：按 source、按标注员维度在 reports/data_bias.json 出分布对比，段2 门禁检查。 |
| 缓解·事后 | 抽 10% 真实照片做 holdout 集（不参与训练）；段3 训练指标以 holdout 为准（承载=08 S6-03/S6-06 n_test≥20 + S6-04 复算）；偏差超阈值则回段2 重新配比，不带病进段3。 |
| 责任方 | DATA（生成/标注配比）、QA（KS 与分布核验） |

### R2 过拟合 —— 模型背训练集、验证集虚高

| 项 | 内容 |
|---|---|
| 等级 | P=3, I=3 → 9 **高** |
| 描述 | 数据量有限（段2 合成 ~5k + 标注 ~2k），四分支共享主干 + 双头结构参数不少，验证集与训练集同源时指标虚高，部署后成对一致率跌落。 |
| 触发信号 | 训练 loss↓ 但 val loss 第 E 轮起↑（gap>0.15）；训练一致率-验证一致率 >0.08；TTA 扰动（±5° 旋转/轻噪声）下子分抖动 >3 分。 |
| 缓解·事前 | ① split 由 `split_of(id)` 确定性切分（80/10/10，C-DATA-01 §2.2），杜绝调参时改划分；② 主干 Dropout 0.1 + 权重衰减 1e-4 + label smoothing 0.1（score 头）；③ 分支宽度预算上限 64 教师 / 48 学生（C-BRANCH-01 §3.1 冻结值），禁止为刷分加宽；④ 早停 patience=8（以 val 成对一致率为准）。 |
| 缓解·事后 | 段3/4 指标不达 AC3/AC4 即冻结发布，回查数据配比与正则强度；段8 用 holdout 复验，确认无训练-部署落差才验收。 |
| 责任方 | MODEL（正则/早停）、QA（gap 与 TTA 抖动核验） |

### R3 标注噪声 —— 分数主观抖动、成对偏好自相矛盾

| 项 | 内容 |
|---|---|
| 等级 | P=3, I=2 → 6 **高** |
| 描述 | 审美打分天然主观；同一样本四维分数标准差可 >15，标注员疲劳导致成对比较出现环形矛盾（A>B>C>A），噪声标签直接教坏 Bradley-Terry 头。 |
| 触发信号 | 同样本四维 SD>15 的占比 >20%；成对环检出率 >5%；两轮复标一致率 <70%。 |
| 缓解·事前 | ① 标注平台内置 8 组蜜月题（gold pair）做注意力过滤，蜜月通过率 <80% 的标注批次降权；② 入库取中位数而非均值（聚合公式=docs/04_LABELING.md §3.2；labels 字段存聚合终值=C-DATA-01 §3.2），`rater_count` 随样本存档供加权；③ 随机抽 10% 双盲复标，一致率入 reports/label_quality.json，段2 门禁（08 S2-08 承载）。 |
| 缓解·事后 | 成对环检测（≥3 环）剔除该环边；SD>15 的样本在 ranking loss 中权重 ×0.5；复标一致率 <70% 的标注员批次回炉重标。 |
| 责任方 | DATA（平台/过滤）、QA（噪声指标核验） |

### R4 性能不达标 —— 延迟/吞吐/参数量门禁失败

| 项 | 内容 |
|---|---|
| 等级 | P=2, I=3 → 6 **高** |
| 描述 | CPU 单图 P95 ≤500 ms、教师 ≤200 ms/学生 ≤80 ms、学生参数 <10M、INT8 权重 <10MB 四条硬指标任一失败，段5/6/8 门禁挂起，Demo 不可用。 |
| 触发信号 | locust P95>500 ms；`reports/params.json` 学生 ≥10,000,000；INT8 文件 ≥10MB；推理超 5000 ms 触发 500。 |
| 缓解·事前 | ① 段3 起每代 checkpoint 出 params.json，宽度按 01_ARCH §4 预算卡死；② 段4 导出即跑单图 CPU 微基准（≤200/80 ms）先于段6 全量 benchmark，问题左移；③ INT8 量化用 ONNX Runtime 动态量化+逐层 scale 校准，校准集 128 张覆盖四子分四分位。 |
| 缓解·事后 | 不达标按序降级：学生宽度 48→40、主干再剪 2 块（保 <10M）、score 头换 int8 → 仍不达标则 branch 头 GAP 改单层线性（对齐 C-BRANCH-01 输出形状不变）；P95 超标先查预处理（resize 在 Pillow 线程池），再开 ORT intra_op=4。**契约（IO 形状/名）永不为性能改**，性能问题只改实现。 |
| 责任方 | MODEL（参数量/量化）、SERVE（推理路径/ORT 配置）、QA（压测复测） |

### R5 版权风险 —— 训练/示例图片权属不清

| 项 | 内容 |
|---|---|
| 等级 | P=2, I=3 → 6 **高** |
| 描述 | 若引入网络抓取照片（Flickr/图库/社交媒体）训练或嵌入 Demo，可能触发著作权与平台 ToS 风险；标注平台若回显原图亦有传播风险。 |
| 触发信号 | data/raw 出现无许可来源清单的文件；sample 出现在 Demo 或文档的第三方可访问位置；报告出现未授权图。 |
| 缓解·事前 | ① 数据来源白名单制：只允许 (a) 程序合成（PIL/numpy 程序化生成，版权归项目）(b) 明确 CC0/CC-BY 且记录 attribution 的素材（data/raw/SOURCES.csv 记文件 sha256+许可+URL）；② 契约与文档示例只用 `docs/contracts/assets/` 自产资产（ARCH 生成，已核 sha256）；③ 段2 门禁：`sh -c "python -m pytest -q tests/test_license_whitelist.py"` 校验 SOURCES.csv 覆盖率 100%（08 S2-07 承载）。 |
| 缓解·事后 | 发现未授权图：立即从 data/ 剔除、git 历史用 filter-repo 清除、重跑受影响训练段；报告附侵权处置记录；标注平台导出只含 id+分数，不含原图像素（图片留在 data/ 内网路径）。 |
| 责任方 | DATA（来源/白名单）、QA（覆盖率核验）、lead（报告终审） |
