# Aesthetic Prism 前端 + 后端增强规划（20+ 新功能）

> 目标：补全模型训练前端功能，增加图片信息比对页（多图并排选优）、
> 素材库批量上传/编辑、文件夹批量评分并排序、以及一系列体验优化。
> 全程遵守 C-SERVE-01 契约错误体，新增端点统一 {"error":{code,message}}。

## A. 后端 API 扩展（新增 8 个端点）

| # | 端点 | 方法 | 用途 |
|---|------|------|------|
| A1 | /assets | GET | 素材库列表（分页/过滤/排序），返回 path/尺寸/bytes/mime/created |
| A2 | /assets/delete | POST | 批量删除素材（json: paths[]） |
| A3 | /assets/rename | POST | 重命名素材（json: path, new_name） |
| A4 | /assets/meta | POST | 批量更新素材元数据（标签/备注，json: {path, tags[], note}） |
| A5 | /assets/upload-batch | POST | multipart 多文件批量上传（files[]），返回逐文件结果 |
| A6 | /score-batch | POST | 文件夹/多图批量评分（json: paths[]），返回逐图评分+总分，按总分排序 |
| A7 | /train/batch | POST | 批量训练（json: {steps, paths[]} 或整库），沿用 train 作业注册表 |
| A8 | /assets/exists | POST | 批量探测素材存在性（前端防重） |

## B. 前端新页面 / 模块

| # | 模块 | 说明 |
|---|------|------|
| B1 | 素材库页 | 网格展示 data/uploads 全部素材，缩略图 + 尺寸/大小/时间，分页 |
| B2 | 多图比对页 | 2~6 图并排（grid 等比缩放），点选高亮做「标记优」→ 汇总到收藏集 |
| B3 | 批量上传 | 多选文件，拖拽多图，上传进度逐文件，结果网格 |
| B4 | 文件夹评分 | 选本地文件夹（webkitdirectory）→ 上传全部 → 评分 → 按总分降序网格 |
| B5 | 素材编辑 | 单图重命名 / 加标签 / 加备注 / 删除 / 复制路径 |
| B6 | 评分结果排序 | 评分后按 total 降序/升序、按单维排序、筛选 |

## C. 体验优化（20+ 项）

1. 全局搜索框：按文件名/标签/备注搜素材
2. 标签筛选：预置标签下拉 + 自定义标签
3. 素材网格排序：文件名/时间/大小/评分
4. 评分历史记录：本地保存已评分图片与分数，可回看
5. 一键复制路径：素材项复制相对路径
6. 素材预览灯箱：点击缩略图放大查看
7. 多选操作：勾选多素材批量删除/打标签/导出
8. 拖拽排序：比对页内拖拽调换位置
9. 评分趋势图：近 N 次评分的 total 折线（本地）
10. 快捷键：←→ 切换比对图，空格打标记
11. 深色/浅色主题切换
12. 上传防重：同名文件提示/跳过/覆盖三选
13. 批量上传进度条：总进度 + 每文件状态
14. 素材统计：总数/总大小/类型分布
15. 剪贴板粘贴上传：Ctrl+V 直接贴图上传
16. 图片尺寸标注：网格卡片标注 WxH
17. 模型加载状态：score 前显示模型是否就绪
18. 错误提示收敛：统一 toast，非阻塞
19. 响应式：窄屏单列，比对页自动换行
20. 教程入口：引导新用户走通全流程
21. 评分对比：同图新旧两次评分 diff 标记
22. 收藏夹：标记为「优」的图单独成集
23. 导出清单：把评分结果导出 CSV
24. 网格密度：紧凑/宽松/列表三档切换
